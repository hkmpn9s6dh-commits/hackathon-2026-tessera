# AGENTS.md — working in this repository

## What this repo is

A protocol, a reference implementation and a static verifier for **offline-verifiable receipts of
AI agent runs**. It is an entry for the Decentralize AI Hackathon (Round 2). Everything a judge
sees is in `README.md`, `docs/` and the live page.

## The four gates (kept from the account's process)

| Gate | Question | Where it lives |
|---|---|---|
| A — before code | Do we agree on what we are building and how it is judged? | `docs/01-SPEC.md` (demo script first, then acceptance criteria), `docs/07-UI.md` §1–4 |
| B — while building | Did we walk the whole path? | tests before implementation, `scripts/verify.sh`, an independent audit ticket |
| C — after building | Can you prove it works? | fresh clone → `bash scripts/verify.sh`, evidence in `docs/04-PROOF.md` |
| D — taste | Would a judge stop at the first screen? | blind ranking against six references, two judges from different families |

Rules that are easy to break and expensive to break:

1. **Do not record the video or design the cover before gate D passes.** This was broken once on a
   previous entry and is recorded in `docs/04-PROOF.md` as a process note.
2. **Scope shrinks after gate A, never grows.** New ideas go into `docs/` as "next", not into code.
3. **Every claim in README has a command.** If it cannot be run, it does not go in the README.
4. **The receipt format is the product.** Do not add a feature to the demo agent that the protocol
   does not need.
5. **Never put prompts, completions or personal data into a bundle.** Hashes only, unless the
   operator deliberately chooses to disclose a step.

## House rules

- TypeScript, strict, `npm run build` = typecheck + Vite. No runtime dependencies in `src/lib`.
- `bin/tessera.mjs` is generated (`npm run build:cli`) and committed, so a clone can run the CLI
  before installing anything. Rebuild it whenever `src/cli.ts` or `src/lib/*` changes.
- `src/samples/*.tessera` are generated by `npm run samples`, which drives the CLI. Never hand-edit
  them: a sample that the CLI cannot produce is a lie.
- Fonts are self-hosted (`src/fonts`), no CDN, no analytics, no cookies.
- Visitor-facing copy is English. `docs/` may be in any language the team reads.
- Windows checkout: `.gitattributes` forces LF. A CRLF checkout changes the bytes of a bundle and
  therefore its hashes — this bit a previous entry, do not remove the file.

## When something fails

1. Reproduce with the exact command in `README.md`.
2. Add a test that fails for the reason you just saw.
3. Fix, run `bash scripts/verify.sh`, commit with the number of checks that changed.
