# 只看图，排个序（6 张，A–F）

这是六张 **1440×900** 的第一屏截图，来自六个不同的产品/比赛站点。请只按「第一眼」排序，不要查这些站点是谁、不要猜哪一张是我们做的。

## 要你做的

1. 看附件 `A.jpg` 到 `F.jpg`（六张都在附件里）。
2. 按这个问句排序：**「如果我是一个评委/用户，打开这一屏，会不会想继续看下去？信息是否一眼抓得住？」**
3. 输出格式（不要多余的话）：

```
1. X — 一句话理由（看到了什么，为什么排这里）
2. X — …
...
6. X — …
```

4. 再说一句：哪一张的**字号**或**留白**明显不对劲。

## 约束

- 只判断图，不联网查出处。
- 不要因为某张是深色/浅色就加减分，只看这一屏能不能读懂、值不值得停。
- 六张里有一张是浅色纸质风格的技术页；如果它排低了，请具体说低在哪（比如层次不清、信息太密、主次不分）。
