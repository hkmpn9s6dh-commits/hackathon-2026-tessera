# Tessera

**Receipts for AI agent runs that anyone can check offline.**

An agent finishes a job and hands you a `.tessera` file — about 500 bytes per step. Drop it into
a static web page with the network unplugged: it tells you whether the run changed after it was
sealed, **which step**, and **which field**. A Merkle proof lets the operator disclose one step
without handing over the rest of the session.

- Licence: MIT. No runtime dependencies, no build step for the CLI (it is committed).

## Verify it in thirty seconds

```bash
node bin/tessera.mjs verify proof/samples/clean.tessera      # PASS, 12 steps, 4 checks
node bin/tessera.mjs verify proof/samples/tampered.tessera   # FAIL — step 4 · result
node bin/tessera.mjs verify proof/samples/forged.tessera     # FAIL — signature
```

The same three samples are on the page as buttons. There is nothing to install and nothing to
trust: the page is static files and the checks are SHA-256 and ECDSA P-256, both from WebCrypto.

## What it claims, exactly

| Claim | How it is checked |
|---|---|
| A step's contents are the ones that were sealed | `h = SHA-256(canonical(step))`, with the previous `h` inside the hash |
| The sequence was not reordered or spliced | every `prev` must equal the previous `h`, and step 0 starts at 64 zeros |
| The whole run has one identity | Merkle root over the step hashes; root of an empty run is 32 zero bytes |
| The root came from this operator | ECDSA P-256 over `tessera/v1\|<runId>\|<root>` |
| One step belongs to the sealed run | Merkle path of ⌈log₂ n⌉ hashes, verified without the other steps |

**What it does not claim.** Tessera proves *this is exactly what the agent recorded*; it does not
prove that what the agent recorded is true. A lying agent can seal a lie. A `model` field is a
declaration, not an attestation of served weights. Selective disclosure hides the other steps; it
does not make the disclosed step private.

## Run it

```bash
npm install
npm run build          # rebuilds the CLI, typechecks, builds the page into dist/
bash scripts/verify.sh # typecheck, 23 unit checks, build, every claim above, 29 browser checks
npm run dev            # the page on http://localhost:4318
```

Regenerating the samples: `npm run samples` (it drives the CLI, so a broken CLI means broken samples).

## Why the demo agent is deterministic

The receipt format is the product; the agent is a stand-in that makes every byte reproducible.
It reads three invoices, redacts phone numbers, writes a digest and asks for approval before
notifying anyone — on a fixed clock, with a scripted policy. `docs/03-INFERENCE.md` shows how to
record a run whose steps come from a real model instead, and what changes (the `model` field, and
nothing else).
